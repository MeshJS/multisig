# Bulk Payment Metadata & Midnight Research

Scheduled for **MRP Month 9 — December 2026**, owned by **Andre**.

## Objective

Research how to add metadata to the current bulk payouts from the task board so
that task-payout metadata can be used by Midnight. The deliverable is a plan file
explaining the metadata design and how the proposed Midnight integration would
work. Implementation is a future decision based on the research.

## Research scope

- Review the existing task-board bulk payout flow and identify where metadata
  would be attached and how individual tasks and payments would be associated
  within a batch.
- Determine what Midnight should enable, who would consume any resulting
  proof, and what they should be able to verify. These are research questions,
  not predetermined requirements.
- Identify an appropriate Midnight project or integration approach; assess
  feasibility, dependencies, limitations, and alternatives.
- Propose a metadata structure with example task-payout and batch payloads,
  including identifiers, versioning, and how a consumer would interpret them.
- Explain which information would be public, private, or selectively disclosed,
  and how any commitments or references would be verified under the proposed
  approach. Distinguish confirmed capabilities from assumptions and open questions.
- Describe the proposed data flow from task-board payout through metadata to
  Midnight consumption or verification, plus implementation and validation steps.

## Proof of completion

A linked plan file containing the research findings, proposed metadata schema
and examples, Midnight integration approach, feasibility assessment, privacy
considerations, open questions, and recommended implementation steps. The plan
must explicitly answer the use-case/consumer and integration-target questions,
or explain unresolved blockers and the evidence needed to resolve them.
